# ASCII Ocean · DSH 背景动画插件

原作者：https://github.com/stackedlol/ascii-sharks

v0.1.0
把 ascii-sharks 动画做成 DSH 会话中栏的活体背景：

v0.2.0
添加了右下角的控制面板

v0.3.0
添加了鲤鱼和金鱼
添加了鼠标点击特效 点击水面会出现波纹 点击鱼身上鱼会受到惊吓

v0.4.0
修复了问题：
1.控制面板不显示数值
2.两个不透明度滑杆的步进不一致
3.浅色主题下首屏背景过暗，文字几乎看不清
4.控制面板点击水里的生物→鲨鱼（原版）→新建会话 新建对话背景仍然是金鱼和鲤鱼

v0.5.0
背景可以延伸到侧边栏，与会话区共用同一片水：鱼群会从侧栏游进对话区，
是一整块连续的水面，而不是两个各自独立、互不相干的动画。

新增设置项
1.「背景延伸到侧边栏」，默认关闭。关闭时完全走 0.4.0 的原有挂载路径，
   不接触任何内联样式，行为与旧版逐字一致。
2.「侧边栏区域不透明度」，默认 0.35。与会话区的首屏/会话内不透明度彼此
   独立，互不影响。

实现要点
1.画布从会话根提升到 AppFrame 层，一张画布同时覆盖两栏，共用同一个
   world，不额外增加 CPU。
2.两段透明度用 destination-out 分别抠出，交界处 48px 线性羽化，不会出现
   硬切边。
3.布局改用几何探测：侧栏列按「位于中栏左侧且高度足够」识别，侧栏面板
   按「仍铺满整列高度」向下收，不再依赖构建哈希类名。DSH 升级换掉
   `mP3x-q_*` / `wtg9ga_*` 时不会静默失效。
4.挂载位置取「同时覆盖两栏的最窄元素」，两栏同父时用该父级，尽量不写
   AppFrame；宿主已有层叠上下文时不再写入 isolation。
5.需要清空的底色沿「填满整列」的链收集，内层 view/列表等局部底色不动。
6.关闭开关或卸载时逐层还原内联样式，不改动其他插件的样式表。

修复
1.单区域模式下元素 opacity 与画布 alpha 重复叠加（会话内不透明度 0.1
   实际渲染成 0.01）。
2.`prefers-reduced-motion` 的静态路径与动画路径行为不一致。
3.侧栏折叠成 56px 导轨时铺满水导致画面拥挤，现改为平滑淡出。
4.羽化渐变此前每帧重建，现按实际变化缓存；两段全不透明时整段抠图跳过。

已知限制
1.依赖 AppFrame 的帧层定位，若上游把会话区改成独立的滚动容器需要重新
   核对几何探测逻辑。
2.Windows 标题栏下两个 position:fixed 按钮的实际位置建议实测确认。
